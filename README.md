# 简谱工坊 · JianPu Studio（桌面应用）
## 注意：本工具使用AI辅助制作；
基于 Electron + Vite + React + TypeScript 的**桌面应用程序**（非网页）：写谱 → 读谱 → 播放。

## 这是什么

一个真正安装/双击运行的 Windows 桌面应用，而不是浏览器里打开的网页。有原生窗口、原生菜单栏、系统文件对话框、快捷键，离线可用。

## 快速开始

### 方式一：直接启动（开发模式）

```bash
# 终端 1
npm run vite          # 启动渲染进程开发服务器 5173

# 终端 2
npm start             # 启动 Electron 窗口
```

或者一条命令同时启动两者：

```bash
npm run dev
```

### 方式二：打包成 exe（推荐）

```bash
npm run pack
```

产物输出到 `release/`：

- `简谱工坊-便携版.exe` — 免安装，双击即用，可放 U 盘随身带
- `简谱工坊 Setup x.y.z.exe` — NSIS 安装包，可装到开始菜单与桌面快捷方式

> ⚠️ 本机注意事项：宿主环境注入了 `ELECTRON_RUN_AS_NODE=1`，会让 Electron 退化成纯 Node 而无法启动。
> 若在终端里手动运行，请先清除该变量：
> ```bash
> env -u ELECTRON_RUN_AS_NODE npx electron .
> ```
> 打包后的 exe 不受此影响。

## 功能

| 模块 | 说明 |
|------|------|
| **可视化编辑** | **点谱面上的音符即选中并响一声**；下方属性面板直接改音高 / 八度 / 时值 / 附点 / 延长 / 力度，加·取消连音线，前插·后插·删除 —— 全程不必手敲语法 |
| **多选连音线** | Shift + 点可跨小节多选，一键连成圆滑线（同音高则自动变延音线）；**支持跨小节**，弧线会画过小节线 |
| 快捷输入条 | 左侧一排按钮（音高/八度/时值/力度/连音线/小节反复），点了就往光标处插 |
| 键盘改谱 | 选中后 `1`–`7` 改音高、`↑↓` 换八度、`.` 附点、`-`/`=` 延长、`←→` 移动、`S` 连音线、`N` 插音、`Delete` 删除 |
| 连奏听感 | 圆滑线内的音用**连奏**发音（起音柔和、延音饱满、音符间不留缝隙）；其余为断奏（干脆收尾、留出呼吸口）——圆滑线听得出来 |
| A/B 对比试听 | 连播两遍：第一遍去掉所有连音线与力度，第二遍原样播放，差别一耳了然 |
| 试听所选 | 选中若干音后一键只放这几音，确认局部效果 |
| 写谱 | 多行文本输入，300ms 防抖实时解析；语法错误带**行号/列号**提示 |
| 读谱 | 渲染成标准印刷简谱：数字、高低八度圆点、八/十六分下划线、增时线、附点、小节线/终止线 |
| 力度 | `ppp–fff` 阶梯力度 + `<` `>` `cresc` `dim` 渐强渐弱（线性插值），标记显示在音符下方 |
| 反复 | `\|:` … `:\|` 整段演奏两遍；支持 `Fine` / `D.C.` / `D.S.` / `§`；反复段落高亮仍对应同一组音符 |
| 拍数校验 | 按拍号核对每小节时值，不足/超出的小节标橙色虚线 + 悬停提示 + 顶部提醒列表 |
| 播放 | Web Audio 双振荡器合成（三角波/正弦 + 高八度泛音 + ADSR 包络），lookahead 调度，音量随力度记号变化 |
| 控制 | 播放 / 暂停 / 停止，BPM 20–240 实时调节（播放中即时重排），当前音符高亮并自动滚动 |
| 示例 | 内置《小星星》《生日快乐》《茉莉花》+ 一个「功能演示」谱（一次看清力度/跨小节连音线/反复） |

> 用法一句话：**点音符 → 改属性 → 播放**。想背语法也能背，工具栏和语法都留着。

### 原生菜单栏

文件（新建 / 载入示例 / **导出谱面为 .txt** / 退出）· 编辑 · 播放（空格播放暂停、Esc 停止、Ctrl+←→ 调速）· 视图（缩放、开发者工具）· 帮助（**F1** 语法说明、关于）

窗口尺寸与位置会自动记忆，下次打开还原。

## 语法

| 符号 | 含义 | 示例 |
|------|------|------|
| `1 2 3 4 5 6 7` | 七个基本音级，默认四分音符（1 拍） | `1 2 3` |
| `0` | 休止符 | `0 0_` |
| `'` / `,` | 后缀，升 / 降八度（可叠加） | `1'` `6,` `5''` |
| `_` / `__` | 后缀，八分 / 十六分音符 | `5_` `1__` |
| `-` | 增时线，把前一音符延长一拍 | `5 - -` |
| `.` | 附点，时值 ×1.5 | `1.` `5_.` |
| `\|` / `\|\|` | 小节线 / 终止线 | `1 2 3 \|` |
| `%` | 注释 | `% 备注` |
| `( )` 包住**不同**音高 | **圆滑线**：上方画弧线，各音仍分别发声，且按**连奏**发音 | `(1 2 3)` |
| `( )` 包住**相同**音高 | **延音线**：自动合并为一个长音，只发声一次 | `(1 1)` |
| `( )` **跨过小节线** | 允许，弧线画过小节线（见下方示例） | `(3 4 \| 5 6)` |
| `ppp pp p mp mf f ff fff` | 阶梯力度，标记显示在音符下方 | `mf 1 2 f 3` |
| `<` / `cresc` / `cresc.` | 渐强：到下一个力度记号之间线性渐强 | `< 1 2 3` |
| `>` / `dim` / `dim.` | 渐弱：到下一个力度记号之间线性渐弱 | `> 1 2 3` |
| `\|:` … `:\|` | 反复记号：两者之间整段**演奏两遍** | `\|: 1 2 3 4 :\|` |
| `Fine` / `D.C.` / `D.S.` / `§` | 到此结束 / 从头反复 / 从记号处反复 / 标记反复起点 | `… 1' - - D.C.` |

**头部设置**（可省略，置于最前）：`1=C` 调号 · `4/4` 拍号 · `100bpm`（或 `♩=100` / `速度=100`）速度

### 综合示例

```
1=C 4/4 96bpm
|: mf 1 2 3 4 | < (5 6 5 4 | 3 2 1 2) | f 3 4 5 6 | p 1 - - - :| ||
```

这段同时演示了：反复记号（`|:` `:|`）、阶梯力度（`mf`/`f`/`p`）、渐强（`<`）、
**跨小节圆滑线**（`(5 6 5 4 | 3 2 1 2)`，弧线画过第 2、3 小节之间的小节线），
且五小节均为 4 拍，不会触发拍数提醒。点「A/B 对比试听」即可直接听出这条圆滑线的效果。

## 技术要点

- 十二平均律，`f = 440 × 2^((midi − 69) / 12)`
- 播放采用 lookahead（40ms 轮询 / 250ms 预排）而非一次性调度，因此**支持任意位置暂停续播**
- contextIsolation + preload contextBridge，渲染进程不开启 nodeIntegration（安全隔离）
- `vite.config.ts` 中 `emptyOutDir: false` — 规避本机 WorkBuddy safe-delete shim 拦截 `fs.rmSync` 导致构建失败

## 已知限制

- 连音线跨到 `|:`（反复起线）或 `||`（终止线）时会被就地收口 —— 这是有意的：跨过反复/终止线的连音线在记谱上没有意义
- 不支持：跳房子（1. / 2. 结尾）、歌词、多声部
- 反复只按标准约定展开一次（不含 `D.C. al Coda` 这类复合指令）
- 换行不等于小节线：跨行连写而漏了 `|` 会被如实判成一个长小节并给出拍数提醒

## 本机打包注意事项

- 打包后 `release/` 目录可能被系统占用而无法覆盖重打包；若遇到
  `The process cannot access the file ... app.asar`，先关闭正在运行的应用，
  或换一个输出目录：`electron-builder --win --x64 -c.directories.output=release-v2`
